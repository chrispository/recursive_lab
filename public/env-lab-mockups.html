Four words to keep nearby

rollout

One model attempt on one task.

verifier

The checker that scores the attempt.

reward

The verifier’s 0–1 feedback. One reward is a single observation, not a training direction.

gradient

The training algorithm looks across many rewards, compares which attempts were better, and computes a direction for changing the policy’s weights. The gradient is not the reward and this page does not calculate it; this page checks whether the rewards are useful enough to feed into training.

rollouts→rewards→gradient→updated policy
Recommended operator path

Package once → run the 2-rollout RL smoke test → inspect per-environment mean/spread/errors → run 4-rollout validation → prepare only the environments that pass. The button labels and disabled states should teach this order.

What the score means

mean

Average reward across attempts. Is the policy getting through?

spread

How much rewards vary. Is there room to improve?

errors

Whether the environment itself failed before scoring.

gradient

Training turns many reward comparisons into a direction for updating the policy. We want a signal with enough variation to point somewhere useful.
