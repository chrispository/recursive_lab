Same run, same 23 criteria. A is what ships today; B–E each attack a different problem with it: the 6px card gutter, the reasoning-block wall, the pass/fail mix, and the fact that this list sits directly under a table but doesn't look like one.

Every criterion is a bordered card on a washed gutter, and every open one reserves a 104px left indent for reasoning. Two passes and a fail cost the same vertical space as a paragraph.

One ruled list, no gutter, no per-card border. Verdict becomes a stamped chip in a fixed column; failures get an inset spine so they're findable without colour alone. Passes collapse by default — a pass with no dispute doesn't need its reasoning on screen.
