Architecture Audit & Consolidation Guide

Comprehensive findings, typography ramp formalization, and table header comparisons for Pages 01–04.

Typography Fix

The "Run Ledger" Font Size

You love the Run Ledger because it is the only object on the site with a 3-level visual hierarchy: 20px subject title → 16px outcome headline → 10px uppercase kicker.

  • Problem: The token scale stopped at 13px (--t-data), so the ledger hardcoded 20px, 16px, and 14px locally.
  • Solution: Expand the official design tokens to include --t-display: 20px, --t-head: 16px, and --t-lead: 14px.
  • Impact: Pages 02, 03, and 04 gain the same confident hierarchy without arbitrary inline styles.
Table Headers

Upgrading Table Header Font & Size

The current table headers use faint 10.5px sentence-case text in muted gray (--text-3), making dense tables feel washed out.

  • Option 1 (Recommended): 10.5px Tech Monospace in bold caps with dark-ground tint (--deep) and crisp hairline bounds.
  • Option 2: 11px Architectural Sans in 650 weight with distinct colored super-header groups.
  • Option 3: 12px Semi-Bold Modern Tabular with high-contrast text.
Consolidation

Page-by-Page Redundancy Elimination

  • Page 01: Invert hierarchy so the Ledger is at the top. Hide the un-wired Recurse card.
  • Page 02: Add a prominent 16px outcome headline before the 11-column table.
  • Page 03: Delete the redundant 14-column single-row table! Don't use red (--fail) for input signal.
  • Page 04: Consolidate the redundant table + card grid into a unified Document Ledger List.
