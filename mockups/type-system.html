Design note · stage 05

Type system and the env lab

Three problems — three font families doing one job, nineteen shipped type sizes across five tokens, and a page that states the same six-row dataset seven times. Below: the evidence, a proposed scale, and three mockups of the env lab under it.

01 What is actually shipping

Counted from public/css/*.css as of this branch. None of these are estimates.

Font families

3

Manrope, Inter, and IBM Plex Mono are all pulled from Google Fonts at four weights each — twelve files. Inter sits in --sans only as a fallback behind Manrope, so it should never render — except that four rules in results.css (lines 30, 61, 89, 95) hardcode it into first position at 10.5px, and those rules are the panel captions and evidence heads used on every page. The captions are therefore set in a different family than every other heading in the app, for no stated reason. base.css also re-declares IBM Plex Mono via local @font-face, duplicating the Google copy, and public/fonts/dm-mono-500.woff2 ships without a single reference.

Distinct type sizes

19

Against a scale of five tokens. The extras: 9, 10, 10.5, 11, 11.5, 12, 12.5, 14, 16, 18, 19, 20px and two clamps. Nine of them land within 1px of a token they should have used. Nobody perceives a 10 vs 10.5 vs 11px distinction — it reads as inconsistency, not hierarchy.

Mono declarations

46

Thirty-five of them are at 9–11px, most uppercase with letter-spacing. That is the least legible combination available, and it is carrying words like package, not built, and recommended path — prose, not data. Mono is being used as a texture.

Uppercase rules

42

Stacked on top of small sizes and mono, uppercase is a third legibility tax on the same text. It should mark exactly one role in the app, not eight.

Font weights

5

400, 500, 600, 650, and 700. 600 and 650 are used interchangeably for the same job — headings — and are barely separable in Manrope. Three weights cover everything this app does.

Reading size

12.5px

--t-body is the default for every paragraph, including the page lede and the review-inbox explainers — sentences you actually read, not scan. It sits half a pixel from --t-data (13px), which is not a scale step; it is noise.

03 Proposed scale

Seven steps, nothing between them, an 11px floor. Tight ratios at the bottom where dense instrument UI lives, wider at the top so a heading actually reads as a heading. Every current ad-hoc size maps onto one of these.

Uppercase gets one job: the panel caption strip (.m-cap h3, .m-panel-head h3) and table column heads. Everywhere else — rail links, field labels, badges, stage names, the collapse toggle — goes sentence case. That alone removes about 30 of the 42 uppercase rules and makes the remaining ones mean something.

B · One ledger

The six environments become one table, and that table is the page. Every per-environment fact the old page scattered across the inbox, the splits table, the proof report, the gate table, and the cluster ledger is now a column or lives inside the row when you open it. The stage machine collapses from four renderings into one command bar at the top, which is also where the run buttons live.

  • Environment count is stated once, in the caption tally. The coverage chain is deleted — it was three copies of that number.
  • The learnability gate stops being a separate table: mean, spread, and saturation become three columns beside the reward, so a row either passes or you can see which of the three killed it.
  • Cluster handoff is a per-row action plus one footer button, not a second listing of the same six names.
  • Costs real TSX work — this deletes ProofReport.tsx and most of Stages.tsx.

Why it failed

Validation ran 4 rollouts across 12 tasks and scored 0.243 against a 0.30 floor. Spread is 0.038 — below the 0.05 learnability minimum — so even lifting the mean would not give the cluster a gradient. The RL smoke test at 0.412 was measured on 2 rollouts and did not survive the wider sample.

Two gates failed independently. A rerun will not help unless the verifier targets change.

A judge model reads each policy answer against the verifier targets. Reward is the fraction of target behavior found, not a human approval score.

C · Workbench

Keeps the queue-and-detail split — it is the best-working part of the current page — and makes it the whole page. Everything below it today either moves into the detail pane, moves into the header strip, or is deleted. One environment is in focus at a time, and that environment carries its own actions instead of sending you down to a shared subway panel.

  • The aggregate row at the top is the only place a total appears. No readiness tally plus proof tiles plus footer row saying variations of the same six numbers.
  • Per-environment run buttons sit next to the number they will change. The global “run everything” buttons stay in the header.
  • Detail tabs go from three to two: Signal (reward, gates, next action) and Package (verifier, splits, paths). The old “Proof signal” tab and the proof report were the same content.
  • Best fit if the mental model is genuinely “work one environment at a time”. B is better if it is “compare six at a glance”.

06 Beyond stage 05

The same three fixes apply everywhere, and the counts above were taken across all ten stylesheets — this is not an env-lab problem that happens to be visible on the env lab.

Data forge (04)

Nine mono declarations, seven of them at 10px uppercase — the review inbox collapse toggle, the recommended-path chip, the queue meta. Its inbox is the pattern the env lab copied, so it gets the same treatment and both get more consistent for free.

Results (03)

Owns all four hardcoded 'Inter' rules. Those are the panel captions used on every page, so this one file is why headings across the whole app render in a family that --sans never mentions. Fixing it is a four-line change with app-wide effect — and then Inter can come out of --sans and out of the font request entirely.

Layout / rail

Carries the 9px sizes — stage numbers and the gate readout. They are the smallest text in the app and sit in the least-read corner, which is the wrong way round. Both go to 11–12px.

Loading cost

Dropping Inter and the 650/700 weights takes the Google Fonts request from twelve files to four. Deleting the duplicate local @font-face for IBM Plex Mono and the unreferenced dm-mono-500.woff2 removes three more files from public/fonts/.
